# 🧠 Productivity Dashboard

A responsive, single-page **Productivity Dashboard** built using **HTML, CSS, and Vanilla JavaScript**.  
This project helps users manage daily tasks, plan their day, stay motivated, and follow focused study sessions using a Pomodoro timer.

---

## 🚀 Features

- 📅 **Live Date & Time Dashboard**
- 🌦️ **Real-time Weather Data** (OpenWeather API)
- ✅ **To-Do List**
  - Add tasks with description
  - Mark important tasks
  - Persistent storage using LocalStorage
- 🗓️ **Daily Planner**
  - Hour-wise planning (6 AM – 12 AM)
  - Auto-reset planner daily
- 💡 **Motivational Quotes**
  - Fetches random quotes using API
- ⏱️ **Pomodoro Timer**
  - Work & break session handling
  - Start / Pause / Reset controls
- 📱 **Fully Responsive Design**
  - Optimized for desktop, tablet, and mobile devices

---

## 🛠️ Tech Stack

- **HTML5**
- **CSS3**
  - Flexbox
  - Media Queries
  - CSS Variables
- **JavaScript (ES6)**
  - DOM Manipulation
  - Fetch API
  - LocalStorage
- **APIs**
  - OpenWeather API
  - Quotes API

---
