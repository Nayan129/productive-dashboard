# 🧠 Productivity Dashboard

A responsive, single-page **Productivity Dashboard** built using **HTML, CSS, and Vanilla JavaScript**.  
This project helps users manage daily tasks, plan their day, stay motivated, and stay focused using a Pomodoro timer.

🔗 **Live Demo:** https://nayan129.github.io/productive-dashboard/

---

## 🚀 Features

- 📅 **Live Date & Time**
  - Real-time clock with day and date
- 🌦️ **Weather Information**
  - Live temperature, humidity, wind speed
  - Powered by OpenWeather API
- ✅ **To-Do List**
  - Add & remove tasks
  - Mark important tasks
  - Persistent data using LocalStorage
- 🗓️ **Daily Planner**
  - Hour-wise planning (6 AM – 12 AM)
  - Automatically resets every day
- 💡 **Motivational Quotes**
  - Random quotes fetched using API
- ⏱️ **Pomodoro Timer**
  - Work & break sessions
  - Start / Pause / Reset functionality
- 📱 **Responsive Design**
  - Works on desktop, tablet, and mobile devices

---

## 🛠️ Tech Stack

- **HTML5**
- **CSS3**
  - Flexbox
  - Media Queries
- **JavaScript (ES6)**
  - DOM Manipulation
  - Fetch API
  - LocalStorage
  - Timers & Events
- **APIs**
  - OpenWeather API
  - DummyJSON Quotes API
